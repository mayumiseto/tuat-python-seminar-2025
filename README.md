## 🧭 目的と内容

### 1. Python Programming Basics

* 来年度の「情報処理学」講義向けの基礎教材。
* Pythonの基本構文、変数、リスト、ループ、ファイル入出力などを扱います。
* Google ColabやJupyter Lab上で実行できるサンプル付き。

### 2. Multivariate Analysis

* 研究室で扱う**環境データ・微生物群集データ**の解析を見据えた応用教材。
* 主成分分析（PCA）、クラスター解析、共分散構造解析などの入門。
* 現在はサンプルデータ（Morimoto et al., submitted）を使用。
